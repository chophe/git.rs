# Gap Analysis: C git vs the Rust Port

Generated by systematic comparison of the C tree (git `v2.55.0-540`) against
the Rust workspace (`crates/`). Method, findings, and the resulting conversion
plan are all derived from observed code, `docs/plan/*` summaries, and
`FOLLOWUPS.md` — nothing is invented.

## 1. How this was measured

1. **Command surface**: extracted the command list from `command-list.txt`
   (~193 real commands, excluding docs/synthetic entries) and diffed it against
   the dispatch table in `crates/git-command/src/lib.rs` and the routing list
   in `scripts/shim-git`.
2. **Behavior depth**: for each ported command, grepped the module for its
   supported option strings and compared against the C builtin's usage (e.g.
   `diff.c`/`builtin/diff.c` implement ~100 options; the port handles 2).
3. **Core subsystems**: compared per-subsystem C files against the
   corresponding Rust crate (`git-odb` vs object-store code, `git-refs` vs
   `refs/`, `git-index` vs `read-cache.c`, etc.).
4. **Cross-checked** the findings against `docs/plan/FOLLOWUPS.md` sections
   A–E and the phase summaries, which agree with the observed gaps.

## 2. Headline numbers

| Metric | C git | Rust port |
|---|---|---|
| Commands in `command-list.txt` | ~193 | **29 routed** (~15% by count) |
| `builtin/` implementation files | 260 (~105k lines incl. diff.c) | 29 modules, ~3.0k lines total |
| Core library (root `*.c`, xdiff, reftable, compat) | ~100k+ lines | ~3.4k lines across git-hash/odb/object/diff/refs/index/merge/revision |
| `t/` test scripts | 1204 | scoreboard tracks pass rate via shim; ~29 commands' worth of scripts run through the Rust path |

Counting commands understates the gap: **depth matters more than count**.

## 4. Commands not ported at all (the big ones, by user impact)

Grouped from `command-list.txt` minus the dispatch table:

- **Workflow core (highest impact)**: `init`, `add`, `commit`, `checkout`,
  `reset`, `rm`, `mv`, `switch`, `restore`, `stash`, `write-tree`,
  `read-tree`, `commit` family (`cherry-pick`, `revert`, `rebase`, `merge`,
  `am`, `format-patch`, `cherry`).
- **History/navigation**: `show`, `shortlog`, `describe`, `blame`, `grep`,
  `whatchanged`, `name-rev`, `show-branch`, `reflog`, `notes`, `replace`,
  `bisect`, `worktree`, `range-diff`, `last-modified`.
- **Remote/transport (largest single subsystem, Phase 11+)**: `clone`,
  `fetch`, `push`, `pull`, `remote`, `ls-remote`, `fetch-pack`, `send-pack`,
  `upload-pack`, `receive-pack`, `http-backend`/`http-fetch`/`http-push`,
  `credential*`, `daemon`, `bundle`, `fast-export`/`fast-import`,
  `filter-branch`.
- **Maintenance**: `gc`, `repack`, `prune`, `prune-packed`, `index-pack`
  (FOLLOWUPS A2), `pack-refs`, `replay`, `maintenance`, `multi-pack-index`
  extras, `fsmonitor*`.
- **Everything else**: `archive`, `attribute` (`check-attr`), `clean`,
  `column`, `config` (!), `difftool`, `cvsserver`/`svn`/`p4`/`archimport`
  (likely out of scope forever), `imap-send`, `mailinfo`, `mailsplit`,
  `mergetool`, `quiltimport`, `send-email`, `shell`, `instaweb`, `gitweb`,
  `gui`/`citool`, `bugreport`, `hook`, `interpret-trailers`, `check-ignore`,
  `check-ref-format`, `check-mailmap`, `mktag`, `merge-index`,
  `merge-one-file`, `merge-tree`, `stripspace`, `var`, `verify-commit`,
  `verify-tag`, `show-index`, `unpack-file`, `update-server-info`,
  `request-pull`, `rerere`, `for-each-repo`, `backfill`, `diff-files`,
  `diff-index`, `diff-pairs`, `annotate`, `diagnose`, `format-rev`, `url-parse`,
  `repo`, `scalar`, `history`, `patch-id`, `pack-redundant`.

Notably, even **`git config`** (the config command) is not routed — the
`git-config` crate only parses/reads files (`parse`, `from_file`, `get`,
`get_all`, `get_bool`); no command, no writes, no includes, no scope rules
(system/global/local), no env overrides (`GIT_CONFIG_*`).

## 5. Core subsystem comparison

| C subsystem | Rust state | Missing |
|---|---|---|
| hash (SHA-1/SHA-256) | `git-hash`, hand-written SHA-1, `is_safe()==false` | sha1dc collision detection (FOLLOWUPS A1); tests `t0013` |
| object store | `git-odb` loose + packs + idx + revindex + delta + midx read/write + commitgraph read/verify + bloom parse | pack bitmaps (EWAH), cruft packs/`pack-mtimes`, commit-graph **write** and chains, bloom **query**, MIDX `RIDX`/`BTMP`/`BASE` chunks, incremental MIDX, `--preferred-pack`, delta **compression** when writing packs (FOLLOWUPS A4), `index-pack` |
| object model | `git-object` tree/commit/tag parse | signature parsing/verification, `gpgsig` rewriting for sha256 conversion (Phase 9) |
| revision walking | `git-revision` RevWalk basic | topo/date order, path limiting, `--first-parent`, grafts/replace, `--all`, `--objects`, boundary handling |
| diff | Myers + unified renderer, byte-identical for plain text | rename/copy detection (`diffcore-rename`), pickaxe, break/rotate, `--stat`/`--numstat`/`--summary`/`--word-diff`, color, function-context hunk headers (userdiff), binary files, no-newline-at-EOF, `--exit-code` semantics |
| index | `git-index` v2 read/write | extensions (TREE cache-tree, REUC, UNTR), versions 3/4, split/sparse index, stat/racy handling, `checkout`/`reset`/`add` machinery |
| refs | `git-refs` files backend + packed-refs read | **packed-refs write**, reflog (`logs/<ref>`), reftable backend, ref locking/transactions, worktree refs, symref writes |
| merge | merge-bases + 3-way line merge | `merge-ort` (rename detection, dir/file conflicts, recursive bases), index merge, conflict clustering parity with `xdl_merge` |
| fsck | reachability + missing/corrupt + dangling | `--strict`, message-catalog parity, sha1↔sha256 conversion + LMAP (gate `t1016`) |
| config | parse/get/bool | `git config` command, writes, include/if-include, scope resolution, env vars, multi-line values edge cases |
| **ignore/attributes** | **nothing** — zero `.gitignore` or `.gitattributes` handling in the port | `.gitignore` (needed for `status --ignored`, `clean`, `add`), gitattributes, clean/smudge filters, line endings (core.autocrlf) |
| **transport/protocol** | **nothing** | pkt-line, protocol v2, fetch/push, pack negotiation, HTTP/SSH/git transports, credential helpers |
| pretty/format/trailers | **nothing** | `pretty.c`, `%(format)`, mailmap, `interpret-trailers` |
| worktree/status dir scan | `status --porcelain` content-compares | stat-info based scanning, racy-clean, `--ignored`, untracked-dir collapse |

## 6. Test-infrastructure gaps (FOLLOWUPS section B)

Done: differential harness, scoreboard (partial), CI workflow
(`.github/workflows/rust-port.yml`), golden fixtures + `gen-fixtures`,
proptest.

Not done:
1. `git-test` crate — Rust replacement for `t/helper/test-tool` (20+
   subcommands listed in FOLLOWUPS B3). Blocks running most `t/` scripts
   without the C build.
2. Fuzz targets (`cargo-fuzz`) for pack/idx/midx/commit-graph/bitmap/index/
   config/reftable/xdiff (FOLLOWUPS B4).
3. Coverage gate ≥90% (`cargo llvm-cov`) in CI (FOLLOWUPS B7).

## 7. Prioritized conversion plan

Ordered by dependency and user impact. Each step should end with: crosswise
suite green, scoreboard no-regression, and the step's `t/` gate named in
FOLLOWUPS.

### P0 — Fill holes in what's already ported (deepen before broadening)
1. **sha1dc** in `git-hash` (A1) — correctness/security prerequisite for
   anything touching SHA-1.
2. **`cat-file --batch`/`--batch-check`** (A3) — unlocks many `t/` scripts.
3. **`rev-parse` completion** (`@{}`, ranges, `--all`) and **ref resolution
   plumbing** for all command args (Phase 4/7 leftover) — nearly every
   command benefits.
4. **`rev-list`/`log` options**: `--objects`, `--count`, `-n`, ranges,
   `--topo-order`/`--date-order`, `--first-parent`, `--all`; then
   `--format`/pretty.
5. **`diff` options**: `--cached`, `-U<n>`, `--stat`/`--numstat`/`--shortstat`,
   rename detection, `--exit-code`, no-newline-at-EOF, binary handling.
6. **`diff-tree --exit-code`**, **`count-objects -v` real sizes** (A5),
   **`--git-dir`/`--work-tree` threading** (FOLLOWUPS C).
7. **`.gitignore` + attributes engine** — hard prerequisite for `status`,
   `add`, `clean`, `ls-files --others`.

### P1 — Make the repo usable (workflow core)
8. **`git init`** (also the template/`--bare`/`--separate-git-dir` paths).
9. **Index write extensions**: cache-tree (`TREE`), REUC; then **`write-tree`**,
   **`read-tree`**.
10. **`git add`** (needs: ignore engine, filters stubbed, index refresh,
    stat handling) → gate `t/t3700`.
11. **`git commit`** (needs `write-tree`, ident with local tz — fixes A6/A7,
    editor plumbing, `-a`, `--amend`, `--allow-empty`) → `t/t7501`.
12. **`git checkout` / `switch` / `restore` / `reset`** (unpack-trees port) →
    `t/t2xxx`.
13. **`git rm` / `mv` / `clean`** (need ignore engine from P0-7).
14. **`git status` full** (long/short formats, branch info, ignored, rename
    detection, stat-based scan).
15. **`git show`**, **`shortlog`**, **`describe`**, **`name-rev`** (thin once
    rev-walk/pretty are done).
16. **`merge` (merge-ort) + `merge-tree` + `cherry-pick`/`revert`/`rebase`**
    (Phase 8 completion) — biggest remaining algorithmic block after diff
    renames.

### P2 — References and history completeness
17. Reflog (read/write, `reflog`, reflog-aware `update-ref`/`branch`).
18. packed-refs **write**, ref **locking/transactions**, `--no-deref`.
19. `pack-refs`, `update-server-info`, `show-index`, `mktag`,
    `check-ref-format`, `stripspace`, `var`, `patch-id`, `check-mailmap`,
    `interpret-trailers`, `check-ignore`, `check-attr` (small, self-contained —
    good xtask-scoreboard wins).
20. `git config` command (read/write, scopes, includes, env).
21. `notes`, `replace`, `worktree`, `reflog`, `bisect`, `stash`, `range-diff`,
    `rerere`, `blame`, `grep`, `archive`, `bundle`.

### P3 — Transport and maintenance
22. `index-pack` (A2), delta **compression** in `pack-objects` (A4),
    bitmaps (EWAH) + `--preferred-pack` + remaining MIDX chunks (completes
    Phase 3), cruft packs, commit-graph **write** + chains.
23. `repack`, `gc`, `prune`, `prune-packed`, `maintenance` (build on P3-22).
24. pkt-line + protocol v2 → `ls-remote` → `fetch` → `push` → `clone`/`pull`
    (largest subsystem; do transports in order: local/file, then git://,
    then HTTP, then SSH; credential helpers last).

### P4 — Stretch / explicitly low priority
25. `apply` completeness (`--3way`, `--index`, binary, `am`, `format-patch`
    completion), `fast-export`/`fast-import`, `filter-branch`.
26. `verify-commit`/`verify-tag` (needs signature stack), `daemon`,
    `http-backend`, `imap-send`, `send-email`, `mailinfo`/`mailsplit`,
    `mergetool`, `difftool`, `instaweb`, `gitweb`, GUIs, `shell`.
27. `scalar`, `backfill`, `diagnose`, `history`, `format-rev`, `url-parse`,
    `repo`, `bugreport`, `for-each-repo`, `column`.
28. Out of scope indefinitely: `cvs*`, `svn`, `p4`, `quiltimport`,
    `archimport`.

### Parallel track — test infrastructure (do alongside, not after)
- **Now**: `git-test` crate (test-tool replacement) — unblocks running real
  `t/` scripts without the C build (FOLLOWUPS B3).
- **Next**: `cargo llvm-cov` coverage gate in CI (B7); fuzz targets for the
  parsers as each lands (B4).
- **Continuously**: every new command gets a crosswise suite + a shim entry +
  FOLLOWUPS/summary update.

## 8. Suggested milestones

| Milestone | Contents | Gate example |
|---|---|---|
| M1 "deepen" | P0 items 1–6 | `t1006`, `t1450`, diff/rev-list crosswise suites |
| M2 "usable repo" | P0-7 + P1 items 8–15 | `t3700` (add), `t7501` (commit), `t2xxx` (checkout) |
| M3 "history complete" | P1-16 + P2 | `t/t6xxx` (merge), `t/t7xxx` (rebase family), reflog tests |
| M4 "self-hosting" | P3-22/23 (all on-disk formats complete) | `t5303`, `t5313`, `t5326` (midx) |
| M5 "networked" | P3-24 | `t5500`–`t5601` (fetch/push/clone) |

Rough scale check against the current codebase: the C reference is ~100× the
Rust line count; M2 is where the port becomes a tool people can actually use
on a repo, and M4/M5 represent the majority of remaining effort (transport is
roughly a phase's worth of work on its own).
