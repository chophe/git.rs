# Phase 10 (stretch) — Summary

Status: **partial** (`git apply` done and cross-verified; `am`, submodules,

network/transport deferred).

## What was implemented

### Commands (`git-command`)
- `git apply [--check] [-p<n>] [--stat] <patch>` — parses a unified diff
  (`diff --git`, `---`/`+++` paths, `new file mode`/`deleted file mode`,
  `@@ -a,b +c,d @@` hunk headers with omitted counts) and applies it to the
  worktree:
  - modifications: hunk-by-hunk with context verification and cumulative
    offset tracking (a hunk's new side replaces its old side — context lines
    preserved, deletions dropped, additions inserted),
  - new files (created, parent dirs made) and deleted files (removed),
  - `--check` verifies hunks apply without writing,
  - `-p<n>` path-component stripping.

## Bugs found & fixed
- Hunk application originally spliced in only the `+` lines, dropping context;
  fixed to splice the full new side (context + additions, in order).
- Patch path prefixes were stripped with `trim_start_matches('a')` (removes all
  leading `a` chars, mangling `a/f.txt` → `/f.txt`); fixed to `strip_prefix("a/")`.
- Test-harness lesson: `git checkout .` / `git reset --hard HEAD` do not
  reliably restore a worktree with staged-new files; the crosswise test restores
  base state explicitly.

## Verified against real git (automated)

`git-command/tests/phase10_crosswise.rs`: a patch containing a modification,
an addition, and a deletion (generated by real `git diff --cached`) applied by
our `git apply` produces file contents identical to real `git apply`, including
file creation/deletion, and `--check` passes on a clean tree.

## Deferred / known limitations

- **`git am`** (mbox + apply), **`format-patch`** — not implemented.
- **3-way apply** (`--3way`, `--base`), `--exclude`/`--include`, `--index`
  (apply to index), `--build-fake-ancestor`, `--reject`, whitespace options
  (`-w`, `--whitespace=...`) — not implemented.
- **`\ No newline at end of file`** markers — parsed past but not honored
  (files are assumed newline-terminated).
- **Binary patches** (GIT binary patch / `--binary`) — not implemented.
- Submodules, notes, blame/line-log, attributes + clean/smudge filters
  (`convert.c`), stash, bisect — not started.
- **Network/transport** (git://, ssh, smart HTTP, protocol v2, fetch/push/
  clone, credential helpers, daemon, `gc`/`maintenance`) — not started.
