## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Tampering | lock.rs symlink escape (refs/heads/x pointing outside .git) | high | mitigate | Canonicalize lock path and reject escapes from the git dir before create; covered by D/F checks in transaction prepare |
| T-01-02 | Tampering | transaction TOCTOU between validation and rename | high | mitigate | Hold every .lock from prepare through commit; abort unlinks all on any failure; no rename inside validation loop |
| T-01-03 | Tampering | reflog message injection via crafted -m text | medium | mitigate | Treat message as opaque bytes after the tab separator; never interpret reflog content as commands |
| T-01-04 | Denial of service | Lock-file squatting with pre-created .lock | medium | mitigate | Stale-lock detection with C-exact error text; never silently unlink a foreign lock |
